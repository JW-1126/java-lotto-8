# java-lotto-precourse

***

### 간단 로또 발매기

> 사용자로부터 로또 구입 금액을 입력받는다.
> <br>입력받은 금액만큼 로또를 발행 및 출력한다.
> <br>사용자로부터 당첨 번호와 보너스 번호를 입력받는다.
> <br>당첨 번호와 발행한 로또들의 숫자를 비교하여 당첨 통계를 확인하고,
> <br>수익률을 계산해 결과로 함께 출력한다.

***

### 기능 요구 사항

- 로또 번호의 숫자 범위는 1~45까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- 로또 1장의 가격은 1,000원이다.
- 당첨 번호와 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, <br>"[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
- Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.

### 주요 기능 목록

- [x] 사용자 입력
    - [x] 구입 금액 입력
    - [x] 당첨 및 보너스 번호 입력
    - [x] 유효한 입력값이 입력될 때까지 예외를 발생, 메시지를 출력하고 다시 입력받는다
- [x] 입력값에 대한 형식 검증
    - 구입 금액
        - [x] 공백, 비어있는 입력을 허용하지 않는다
        - [x] 구입 금액으로 양의 정수 외의 데이터는 입력될 수 없다
        - [x] 구입 금액은 1000으로 나누어떨어지는 양의 정수만 가능하다
    - 당첨 및 보너스 번호
        - [x] 공백, 비어있는 입력을 허용하지 않는다
        - [x] 당첨 및 보너스 번호로 양의 정수 외의 데이터가 입력될 수 없다
        - [x] 당첨 및 보너스 점수는 1에서 45사이의 정수만 가능하다
        - [x] 당첨 번호는 중복되지 않아야한다.
        - [x] 당첨 번호는 정확히 6개의 정수가 입력되어야한다
- [x] 출력
    - [x] 에러 메시지 출력
    - [x] 구매한 로또 번호 출력
    - [x] 당첨 통계 출력
- [x] 구입 금액만큼의 로또 구매 및 값 보관
- [x] 당첨 통계 계산
- [x] 수익률 계산
